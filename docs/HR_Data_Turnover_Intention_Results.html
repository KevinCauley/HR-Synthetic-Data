Turnover Intention Modeling

Predicting Employee Turnover Intention

This section develops predictive models to identify key drivers of employee turnover intention, using statistical and machine learning techniques to uncover actionable insights for workforce retention.

Modeling Overview

Following exploratory analysis, predictive modeling was conducted to identify the most important drivers of employee turnover intention. Multiple machine learning algorithms were evaluated to capture both linear relationships and more complex, non-linear workforce dynamics.

Data Preparation

Prior to modeling, numeric predictors were standardized where appropriate and categorical variables were encoded to ensure compatibility with machine learning algorithms. The target variable for this analysis is Turnover Intention.

Models Evaluated

  • Logistic Regression
  • Regularized Logistic Regression
  • Random Forest
  • Gradient Boosted Trees
  • Support Vector Machines

Class Balancing Strategies

  • No Sampling
  • Up Sampling
  • Down Sampling
  • SMOTE

Evaluation Metrics

  • Accuracy
  • Precision
  • Recall
  • F1 Score
  • Specificity
  • ROC AUC

Special emphasis is placed on recall and F1 score, as correctly identifying at-risk employees is more critical than maximizing overall accuracy.

Modeling Approach and Evaluation Framework

The objective of this section is to predict Turnover Intention using behavioral, demographic, and engagement-related predictors. Models are evaluated across multiple class balancing strategies to ensure robust and fair performance comparisons.

This framework provides a structured approach to identifying the most effective predictive model while maintaining interpretability and practical relevance.

Model Setup and Validation Strategy

Baseline Model: Logistic Regression

Logistic regression is used as a baseline model to establish a benchmark for performance. Its interpretability allows for clear understanding of relationships between predictors and turnover intention.

Logistic Regression served as a transparent and interpretable baseline model across all resampling strategies. While it did not outperform more complex models in any single metric, it provided consistent and stable performance, making it valuable for benchmarking and stakeholder communication.

  • SMOTE delivered the strongest balance across metrics, achieving the highest recall (0.478) and F1 score (0.484), making it the most effective configuration for identifying at-risk employees.

  • Up Sampling produced the highest precision (0.463) and specificity (0.596), indicating improved performance in reducing false positives.

  • Down Sampling demonstrated consistent performance across all metrics, matching SMOTE in recall, precision, and F1 score (0.478), though with slightly lower overall discrimination (ROC AUC = 0.437).

  • No Sampling achieved the highest specificity (0.670) and strong accuracy (0.527), but under performed in recall (0.359), highlighting the impact of class imbalance.

Overall, Logistic Regression provides a reliable baseline model, but its limitations in capturing complex patterns suggest that more advanced models may offer improved predictive performance.

Key Insight: Logistic regression provides a stable and interpretable baseline, but struggles to capture complex workforce patterns, indicating the need for more advanced models.

Interpretation — Random Forest with Down Sampling

Down sampling was used to reduce class imbalance by limiting the number of majority-class observations during training. This approach often helps the model become more responsive to the minority class, which is valuable when the primary goal is identifying employees at risk of turnover intention.

In this Random Forest configuration, the results should be interpreted by balancing sensitivity against specificity. If sensitivity improves meaningfully compared to the baseline model, the down-sampled version may be more useful for early identification purposes, even if overall accuracy declines slightly. The confusion matrix and ROC curve together help determine whether this tradeoff is acceptable within the project’s workforce analytics context.
