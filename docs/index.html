Workforce Analytics Using Synthetic HR Data

An end-to-end HR analytics pipeline leveraging synthetic data to model employee behavior, predict turnover risk, and generate actionable workforce insights.

🔍 Project Overview

This project simulates a real-world HR analytics environment using synthetic data informed by industry trends. It demonstrates how organizations can build scalable data pipelines to analyze workforce behavior, predict employee outcomes, and support data-driven decision-making.
Core Focus: Turnover Intention • Quiet Quitting • Monitoring-Based Risk
